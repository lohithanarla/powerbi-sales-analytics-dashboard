# powerbi-sales-analytics-dashboard
Project Name :
Interactive Sales Analytics Dashboard using Power BI and Excel

Project Overview :
Developed an interactive and dynamic Sales Dashboard in Power BI to monitor and analyze key business metrics such as Sales, Profit, Quantity Sold, Product Performance, Sales Channels, and Payment Modes. The dashboard enables users to explore data through interactive filters and visualizations, helping stakeholders make informed business decisions based on real-time insights.

Tools and Technologies :
	Power BI Desktop
	Microsoft Excel (Data Source)
	Power Query (Data Cleaning & Transformation)
	DAX (Data Analysis Expressions) (KPIs and Measures)
	Data Modeling
	Data Visualization Techniques

Dashboard Features :
o	Interactive slicers for Year, Month, Sale Type, and Payment Mode
o	KPI Cards displaying:
	Total Sales
	Total Quantity Sold
	Total Profit
	Profit Percentage
o	Monthly Sales and Profit Trend Analysis
o	Daily Sales Performance Tracking
o	Product-wise Sales Analysis
o	Category-wise Sales Analysis using Treemap
o	Sales Distribution by Type (Direct, Online, Wholesaler)
o	Payment Mode Analysis (Cash vs Online)
o	Dynamic filtering and cross-visual interaction across all reports

Data Preparation : 
	Imported sales data from an Excel workbook into Power BI.
	Cleaned and transformed raw data using Power Query.
	Verified data consistency and handled missing or duplicate records.
	Created relationships between relevant data fields for accurate analysis.
	Structured the dataset for efficient reporting and visualization.

Data Analysis :
o	Calculated key performance indicators (KPIs) using DAX measures.
o	Analyzed monthly and daily sales trends to identify performance patterns.
o	Evaluated profit contribution across different periods.
o	Identified top-performing products and categories based on sales value.
o	Compared sales generated through various sales channels.
o	Analyzed customer payment preferences using payment mode data.
o	Generated actionable insights to support business decision-making.

Dashboard Preview :
The dashboard provides a comprehensive overview of business performance through visually appealing and interactive reports. It includes KPI cards, bar charts, line charts, donut charts, and treemap visualizations. Users can dynamically filter data by year, month, sales type, and payment mode to explore trends, compare performance metrics, and uncover business insights in real time.

Key Results :
	Total Sales: ₹367K
	Total Profit: ₹34K
	Total Quantity Sold: 132 Units
	Profit Margin: 10%
